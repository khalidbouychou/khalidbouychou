## About

Software engineer trained at **1337 / 42 Network** (peer-to-peer, project-based, no lectures), now shipping
multi-service production software end to end — from the Postgres schema and the queue workers up to the React
dashboard and the browser extension that drives it.

- 🏗️ **Currently** — full-stack engineer on a multi-tenant automotive SaaS platform: an Express + Drizzle + Postgres
  REST API with BullMQ background workers, a React 19 dashboard, a Chrome MV3 extension that automates marketplace
  listings, a Next.js multi-tenant site renderer, and a Puppeteer/FFmpeg video-render microservice.
- 🔧 **Across the whole stack** — I do not stop at the framework boundary: the migration, the worker, the API
  contract, the UI, the Dockerfile, and the CI pipeline.
- ⚙️ **Systems foundations** — C and C++ written from scratch at 42: an IRC server, a threaded dining-philosophers
  simulation, UNIX signal-based IPC. It pays off as sharper debugging everywhere else.
- 🤖 **AI-native workflow** — LLM app integration (Gemini API), MCP servers, and agent tooling as part of how I
  build, not as a side interest.
- 🌍 Arabic · French · English
